# 02: 학생 글쓰기 화면

**What to build:** 학생이 수업을 선택하면 수업 정보를 보고 세 가지 질문에 답한 뒤 임시 저장하거나 제출할 수 있게 한다.

**Blocked by:** 01: 학생 첫 화면

**Status:** ready-for-agent

- [ ] 브라우저에서 수업 제목과 날짜가 보인다.
- [ ] 세 가지 질문과 답변 입력 칸이 보인다.
- [ ] 답변을 입력할 수 있다.
- [ ] 임시 저장 버튼과 제출 버튼이 보인다.
- [ ] 임시 저장한 답변이 브라우저를 새로 열어도 남아 있다.
- [ ] 제출 후 학생 첫 화면에서 글 작성 여부가 바뀌어 보인다.
