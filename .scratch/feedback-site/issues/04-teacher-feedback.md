# 04: 선생님 피드백 화면

**What to build:** 선생님이 학생 글을 열어 답변을 읽고 세 가지 피드백을 작성해 저장할 수 있게 한다.

**Blocked by:** 03: 선생님 첫 화면

**Status:** ready-for-agent

- [ ] 학생별 제출 목록에서 학생 글을 열 수 있다.
- [ ] 반·번호·학생 이름이 보인다.
- [ ] 수업 제목과 날짜가 보인다.
- [ ] 학생의 세 가지 답변이 보인다.
- [ ] 피드백 입력 칸이 보인다.
- [ ] 피드백을 저장할 수 있다.
- [ ] 이전 학생·다음 학생 버튼이 보인다.
- [ ] 저장한 뒤 학생 화면에서 피드백 도착 여부가 보인다.
