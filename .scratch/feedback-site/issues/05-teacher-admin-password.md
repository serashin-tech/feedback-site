# 05: 선생님 관리자 비밀번호 보호

**What to build:** 선생님 화면을 열기 전에 관리자 비밀번호를 입력하게 하고, 올바른 비밀번호를 입력한 뒤에만 학생 글과 선생님 전용 내용을 확인할 수 있게 한다.

**Blocked by:** 04: 선생님 피드백 화면

**Status:** ready-for-agent

- [ ] 브라우저에서 선생님 화면을 열려고 하면 관리자 비밀번호 입력 화면이 먼저 보인다.
- [ ] 실습용 비밀번호 `teacher-demo`를 입력하기 전에는 선생님 첫 화면이 보이지 않는다.
- [ ] 비밀번호를 입력하기 전에는 학생 글, 제출 목록, 피드백 내용 등 선생님만 보는 내용이 보이지 않는다.
- [ ] 잘못된 비밀번호를 입력하면 선생님 화면이 열리지 않고 안내 문구가 보인다.
- [ ] `teacher-demo`를 입력하면 선생님 첫 화면이 열린다.
